PATRICK J. MCLAUGHLIN LEADERSHIP WEBSITE

This folder is a complete static website. No build process or paid hosting is required.

RECOMMENDED FREE PUBLISHING: GITHUB PAGES
1. Create a free GitHub account at github.com if you do not already have one.
2. Create a PUBLIC repository named: yourusername.github.io
   Example: if your username is pjmclaughlin, use pjmclaughlin.github.io
3. Upload EVERY file and folder from this package to the repository root. Keep the assets folder intact.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, then main / root.
6. Your website will appear at https://yourusername.github.io

ALTERNATIVE
You can also upload the same files to Cloudflare Pages or Netlify. The site uses plain HTML/CSS and requires no server.

IMPORTANT WHEN EDITING
- Keep index.html, style.css, the four downloadable document files, and the assets folder together.
- If you rename a PDF or Word document, update its filename in index.html.
- Replace assets/patrick-mclaughlin-headshot.webp if you later choose a different headshot, keeping the same filename for the easiest swap.
